# 对《桌面端GUI全量测试报告》的改进建议

报告质量高（分级、证据、限制说明清楚）。可再加强如下几点：

## 报告本身

1. **附录 A 与正文矛盾**：正文写「新建本地标签数 +1」，附录大量「无可见变化」且延时 ~1s（像超时）。应统一判定口径，或注明附录为「首轮空标签污染数据已作废」。
2. **P0 应附复现脚本**：G-01/G-02/G-03 建议附 Bridge/`WM_COMMAND` 一步复现命令，方便回归门禁。
3. **覆盖缺口单列**：UAC、退出、中间节点删除、Ctrl+Tab 已在概述说明，建议在缺陷表增加「未测风险」行，避免读者当成已通过。
4. **状态断言字段**：除 tabs/state 外，增加 `term_hwnd_count`、会话树节点数到 Bridge `/state`，减少「截图像素差分」依赖。
5. **性能表注明样本**：表8 写「中位数级别」但多数单次；改为 n=3 取中位，SSH 建连注明网络环境。

## 产品侧（报告已指出、应优先改）

| 优先级 | 项 | 动作 |
|--------|-----|------|
| P0 | G-01 首标签空白 | `WM_CREATE` 最先赋值 `g.hwnd` |
| P0 | G-02/G-03 锁拷贝 | 会话用字段拷贝，禁止整结构体含 CS 赋值 |
| P0 | G-04 导入覆盖 | 备份 + 确认框 |
| P1 | 空输入静默 | 发送/查找：置灰或状态栏提示 |
| P1 | 本地按钮读 Shell | 工具栏「本地」读取 `cmb.shell` |
| P1 | 重连 | 本地/串口给出「不支持」提示；SSH 正确重建 |

## 协议面（本轮产品调整）

- 去掉 RDP / VNC（旁载体验弱、菜单噪声大）
- 增加 **Telnet**（独立 `engine/telnet_session.c`）
- UI / 连接 / 会话树继续拆模块，避免 `main.c` 继续膨胀
