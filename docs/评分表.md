# YTerminal 多维评分表（满分 10 分 / 每项逐维打分）

> 打分口径（本表自定，先说明再打分，避免自说自话）：
> 1. **每个维度独立打 0–10 分**，10 = 该维度在同类工具里也属第一梯队，且经实测无误；9 = 优秀但仍有可见缺口；7–8 = 可用、有明确短板；≤6 = 明显不足。
> 2. 打分**必须有证据**：代码位置、测试结果、截图或实测命令；没有证据的维度不得高于 8。
> 3. 只报分数不够，**每个非 10 分项必须写出「差在哪」和「怎么补」**；本轮能补的当场补，补完重新打分（见 §3 迭代记录）。
