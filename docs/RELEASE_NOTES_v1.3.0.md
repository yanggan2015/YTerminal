# YTerminal v1.3.0

纯 C、单 EXE 283 KB 的 Windows 全能终端。

## 本版重点：快捷键真正"可自定义"

### 1. 快捷键设置（`Ctrl+Shift+M`）

- 20 个动作（复制/粘贴/查找/全选/日志/分屏/快捷命令/SFTP/命令面板/关闭标签/新建标签/字号/设置/一览/端口转发/广播/快捷键设置）全部可改键
- **录制式改键**：选中一行 → 点「修改」→ 直接按下新组合键
- **冲突当场拦截**：与「粘贴」冲突时明确提示「与『粘贴』冲突，未修改」，原键保持不变
- **单键误触拦截**：不带 Ctrl/Alt/Shift 又不是 F1–F24 的组合会被拒绝
- 「全部默认」一键还原；「保存」写 `settings.json` 并立即生效；「取消」整批回滚
- 键名支持 `Ctrl+Shift+P`、`F11`、`Ctrl+=`、`Ctrl+Tab`、`Ctrl+,`、`Ctrl+/` 等写法

### 2. 快捷键一览读实时键位

不再是写死的静态表：改完键再打开一览，看到的就是当前键；不可自定义的固定键（Esc / Alt+字母 / Shift+Tab）单独列在末尾，并新增「自定义…」按钮直达设置。

### 3. 新模块 `src/keymap.c/h`

键名解析、反向格式化、冲突检测、序列化（`0=Ctrl+Shift+C;1=...`）全部是纯逻辑，无 UI 依赖；终端按键分发从两段硬编码 `switch` 改为查表，命中即派发命令。
