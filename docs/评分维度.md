# YTerminal 10 维评分体系

每个功能点满分 **10 分 × 10 维 = 100 分**。实现后评分，不达标则改，改完再评，目标满分。

| # | 维度 | 说明 | 满分判据 |
|---|------|------|----------|
| 1 | 功能完整 | 需求能力是否齐、边界是否覆盖 | 主路径+异常路径均可用 |
| 2 | 用户体验 | 操作路径短、反馈清晰、快捷键合理 | 3 步内完成主操作 |
| 3 | 界面美观 | 布局层次、对比度、字体、间距 | 无拥挤/错位，终端区可读 |
| 4 | 响应性能 | 输入延迟、滚动、重连、大数据量 | 键入 <50ms 感知，滚动流畅 |
| 5 | 稳定性 | 崩溃、泄漏、断线恢复、异常输入 | 压力与异常不断崩 |
| 6 | 代码质量 | 可读、无警告、边界检查、错误处理 | 编译 0 warning 关键路径 |
| 7 | 架构设计 | 模块边界、会话抽象、扩展性 | 新会话类型可插拔 |
| 8 | 可测试性 | UI Bridge、状态导出、可断言 | tree/state/action 闭环 |
| 9 | 安全性 | 凭据存储、本机调试口、输入校验 | 无明文乱存；桥接仅 127.0.0.1 |
| 10 | 可维护性 | 文档、命名、构建、执行记录 | 新 Agent 可据文档接手 |

## 评分规则

- 每维整数 0–10；总分 = 十维之和。
- 单项 <8 必须修；总分 <95 继续迭代。
- 评分写入 `docs/评分表.md`，附日期与问题清单。
