# YTerminal vs WindTerm / MobaXterm / SecureCRT

对比基准：2026-11-15 当前 `dist/YTerminal` 界面与能力。  
结论先行：**能连、能绿、能测，但离「商用主力终端」的界面与打磨差一大截。**

图例：● 到位 / ◐ 半成品 / ○ 缺失或明显弱

---

## 1. 界面与交互（差最多的地方）

| 能力 | WindTerm | MobaXterm | SecureCRT | **YTerminal 现在** | 差距说明 |
|------|----------|-----------|-----------|-------------------|----------|
| 视觉层级/主题 | ● 深色主题、标签着色 | ● 工具箱风 | ● 企业稳重 | ○ 默认 Win32 灰白条 | 像原型，不像成品 |
| 会话树体验 | ● 分组/搜索/图标 | ● 书签树 | ● 会话夹 | ◐ 仅列表树 | 无图标、无拖拽、无右键菜单 |
| 连接工作流 | ● 会话对话框完善 | ● 一站式新建 | ● 属性页很全 | ◐ 顶栏填空连接 | 无独立「新建会话」向导/属性页 |
| 工具栏/快捷命令 | ● Quick Bar/命令面板 | ● 宏按钮 | ● 按钮栏 | ○ 几乎无 | 缺常用命令条 |
| 状态信息 | ● 延迟/编码/行列 | ● 丰富 | ● 连接状态细 | ◐ 一行 Static | 无编码、延迟、光标行列 |
| 多语言 UI | ● | ● | ● | ○ 英文控件字 | 无中文界面 |
| 标签管理 | ● 着色/关闭右侧/搜索 | ● | ● 标签组 | ◐ 基础 Tab | 无右键菜单、无锁定 |
| 分屏 | ● 任意拆分 | ● | ● 布局 | ◐ 简陋左右 | 无拖拽分割条、无布局保存 |
| SFTP UI | ● 双栏文件管理器 | ● 侧栏成熟 | ◐ 靠 SecureFX | ◐ ListBox+三按钮 | 无拖拽、无路径栏、无权限列 |
| 终端选区 | ● 块选/流选 | ● | ● | ○ 仅整屏复制 | **无鼠标拖选** |

**界面一句话**：三家是「产品壳」；我们现在是「功能控件堆在 Win32 默认皮肤上」。

## 5. 必须补齐的优先级（按「像不像商用」）

### P0 — 不补就不敢卖「对标三家」
1. **终端：鼠标选区复制、右键菜单、更好 ANSI/256 色**  
2. **会话：属性对话框（SSH/串口分頁）、树右键（连接/编辑/删除/克隆）**  
3. **UI 皮肤：深色终端区 + 统一工具栏图标/间距（别再纯系统灰条）**  
4. **SFTP：路径栏、双击进目录、进度与错误提示**  
5. **状态栏：协议、编码、行列、连接耗时**

### P1 — 对标 Wind / SecureCRT 体验
6. 快捷命令条 / 宏录制回放  
7. ProxyJump 真正可用 + 密钥选择器  
8. 分屏拖拽 + 布局保存恢复  
9. 日志选项（时间戳/仅主机）  
10. 中文 UI

### P2 — 对标 Moba 全能
11. 内嵌或深度集成 RDP/VNC/X11（不止拉进程）  
12. 完整 ZMODEM  
13. 多执行/广播面板可视化

## 6. 诚实评分（相对三家整体完成度）

| 维度 | 相对完成度（估） |
|------|------------------|
| 能连上、便携分发 | ~70% |
| 协议广度（名义上） | ~60% |
| 终端仿真质量 | ~35% |
| 会话管理与工作流 | ~40% |
| **界面与产品感** | **~25%** |
| 企业打磨（脚本/布局/稳定压测） | ~20% |

**总评**：骨架和绿色分发有了；**界面和终端交互是当前最大短板**，不能拿「功能列表打勾」冒充已经追上 WindTerm/Moba/SecureCRT。
