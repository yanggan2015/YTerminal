## 新功能

- **全局命令面板（Ctrl+Shift+P）**：26 条命令 + 全部会话，子序列模糊匹配并按命中质量排序；↑↓ 选择、Enter 执行、Esc 关闭；标签右键菜单也可打开。
- **关键字高亮**：设置里逐行写 `文本=>#RRGGBB`，终端输出命中即按规则着色；预置 ERROR / WARN / FAILED / SUCCESS / 拒绝访问 / Permission denied。
- **端口转发管理器**：`L:/R:/D:` 规则可在界面逐行编辑，保存前校验端口与格式，坏行提示「第 N 行格式不正确」，写回会话并提示重连生效。
- **快捷键一览**：双列 18 条速查，键名右对齐灰色、说明深色。
- **标签右键增强**：重命名 / 复制会话 / 重连 / 复制标题 / 关闭 / 关闭其他 / 关闭右侧 / 命令面板；批量关闭前二次确认。
- **窗口几何记忆**：退出记录位置尺寸，下次启动原样恢复（越界自动回退）。

## 修复

- 命令面板 use-after-free（改为销毁窗口后统一派发）
- 删除左侧标签后 `active_tab` 错位
- 多处 `COLORREF` 误用导致的黑块 / 文字隐形
- 快捷键窗口右列文字变色（改用原生 STATIC 控件）
- 高亮规则多行编辑不换行（多行 EDIT 需 CRLF）

- 新增 `docs/功能清单.md`（主流终端优点 8 大类 54 条）与 `docs/评分表.md`（12 维评分，当前 8.0 / 10，含两轮优化复评记录）
