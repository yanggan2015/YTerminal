## 3. 配置文件

| 文件 | 用途 |
|------|------|
| `config/sessions.json` | 连接/会话书签（协议、主机、串口、跳板等；密码在 creds.bin） |
| `config/window.json` | 窗口位置尺寸、面板显隐、分屏、主题、字体、透明度、粘贴延迟 |
| `config/creds.bin` | DPAPI 加密密码 |

退出时自动保存；菜单「保存/恢复窗口配置」「导入/导出会话」。

## 4. 门禁

1. Bridge：`python scripts/full_bridge_test.py` 全 PASS。  
2. 菜单项必须有 `WM_COMMAND` 分支，禁止灰项占位。  
3. 《终端调研》亮点须标注 ✅已实现 / ⏳半成品。
