## 2026-11-15 — 修复 PowerShell/串口卡顿

### 实测
- Local PowerShell：ConPTY 全路径启动，状态栏缓冲可达数十行；`term.view` 可见
- COM5 @115200：登录+命令，缓冲约 30 行
- COM3 @1500000：连接栏可填 COM/波特率（此前被藏掉）

### 修复
- `local_pty.c`：可继承管道/句柄标志、全路径 powershell、空读不退出、启动后 resize
- `serial_session.c`：大驱动缓冲、读写分线程、输出 16ms 合并、写不堵 UI
- 连接栏按种类显示 SSH 字段或 COM/波特率
