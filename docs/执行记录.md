## 1. 需求与约束

1. 做一款**完整的 Windows 终端工具**，对标 **WindTerm / SecureCRT / MobaXterm**，并尽量在易用性、体积、启动速度上优于它们。
2. 原始会话中明确提出的硬约束：**不使用 Python，纯 C 语言实现，节省空间**（来源：用户提供的豆包会话分享页，仅公开了这一句）。
3. 允许去 GitHub 下载主流终端工具源码到 `参考/` 目录作参考（已完成：alacritty、tabby、Windows Terminal、wezterm）。
4. 交付要求：可编译运行的完整工具 + GitHub 仓库（创建仓库并提交推送）。

## 2. 现状总览

- 形态：纯 Win32 / GDI 单文件 EXE，无第三方运行时依赖。
- 构建产物：`build/YTerminal.exe`（约 268 KB）+ `build/YTPass.exe`（SSH_ASKPASS 密码桥，约 42 KB）。
- 构建脚本：`build.ps1`（自动收集 `src/*.c`，windres 编资源，静态链接，`-mwindows`）。
- 参考源码：`参考/opensource/{alacritty,tabby,terminal,wezterm}`；`参考/notes` 为空。

### 2.2 已实现功能（截至本次记录）

- 协议：SSH（系统 OpenSSH，支持私钥/Agent/键盘交互、保活、跳板 `-J`、`-L/-R/-D` 隧道、附加参数）、Telnet（IAC 协商、NAWS、TTYPE）、串口（波特率/数据位/校验/停止位/流控/DTR/RTS/Break）、本地 Shell（ConPTY）。
- 会话管理：分组、收藏、备注、前缀搜索、快捷命令（`命令|说明`）、触发器、DPAPI 加密保存密码、便携模式。
- 界面：多标签、左右/上下分屏、输入广播、侧边栏、工具栏、状态栏、标签重命名/复制、工作区恢复。
- 终端：256 色/24 位真彩、粗体/斜体/下划线/反显、宽字符与组合符、备用屏、滚屏缓冲、鼠标上报、括号粘贴、OSC 0/2 标题、OSC 9/777 通知、BEL、IME 输入、Ctrl+滚轮缩放、搜索（高亮/上一个/下一个）、选区复制、右键菜单、日志（可自动）、断线重连。
- 外观：多套主题、透明度、字体字号、光标样式/闪烁、行距、DPI 感知（per-monitor v2）。
- 传输：基础 SFTP 窗口（列目录/上传/下载/删除），命令行批处理实现。
- 导入：SecureCRT、MobaXterm、PuTTY 注册表、**OpenSSH `~/.ssh/config`**。
- **会话编码**：UTF-8 / GBK / BIG5 / Shift-JIS / EUC-KR；入站解码保留跨包半字符，出站按会话编码转换；广播输入逐会话独立转换。
- **Ctrl+点击链接**：`http(s)://`、`ftp://`、`file://`、`www.`；命中时手型光标，`ShellExecuteW` 打开。
- **拖放文件**：本地会话插入带引号路径；SSH 会话后台 `scp` 上传到远端家目录，状态栏回显；其他协议提示改用 SFTP 窗口。
- **全局命令面板**：Ctrl+Shift+P / 标签右键「命令面板…」，26 条命令 + 全部会话条目，模糊（子序列）打分排序，↑↓ 选择、Enter 执行、Esc 关闭；自绘列表带选中竖条与右侧快捷键提示。
- **关键字高亮**：设置里「高亮规则」多行编辑，`文本=>#RRGGBB`（可 `#` 注释、`;` 分隔），逐行大小写不敏感匹配后按规则色重绘该行文本；预置 ERROR/WARN/FAILED/SUCCESS/拒绝访问/Permission denied 六条。
- **快捷键一览**：命令面板「快捷键一览」打开，双列 18 条（原生 STATIC，键名右对齐灰色、说明左对齐），底部提示标签右键能力。
- **端口转发管理器**：会话可逐行编辑 `L:/R:/D:` 规则，保存前用 `yt_fwd_parse` 校验并 `yt_fwd_format` 规范化，坏行弹「第 N 行格式不正确」，写回会话 JSON 并提示「重连后生效」。
- **标签右键增强**：重命名 / 复制会话 / 重连 / 复制标题 / 关闭 / 关闭其他 / 关闭右侧 / 命令面板，共 8 项。

## 6. 交接注意事项

- 源码中文注释为 **UTF-8 无 BOM**，用 PowerShell `Get-Content` 直接读会显示为乱码，请用 `Read` 工具或指定编码读取，**不要**用默认 ANSI 重写文件，否则会毁掉注释。
- 所有 GUI 验证走 `computer_use_tool`（桌面 `cu` / 浏览器 `bu`），先读对应 Skill。
- 终端颜色编码为 `0x01RRGGBB`（VT 编码），绘制前必须经 `app_cr()` 转 GDI `COLORREF`，历史 bug 就出在这里。
- 密码落盘使用 DPAPI（`yt_dpapi_encrypt_hex`），不要改成明文。
- 提交前确认 `build/`、`参考/` 不被误提交（见 `.gitignore`）。
- 对话框坐标全是**客户区坐标**：`SetWindowPos` 设窗口高度时必须加上非客户区差值（`GetWindowRect - GetClientRect`），否则底部按钮会被标题栏顶出可视区。
- `mkdir`/`rm` 等别用 Unix 语义；本机 Bash 工具不可用，一律用 PowerShell。中文控制台输出会乱码，判断窗口靠尺寸/句柄而不是标题字符串。

### 7.2 本轮踩坑（写给下一个 Agent，别重复踩）

1. **`COLORREF` 混用**：`theme->bg` 等是 `0x01RRGGBB`，直接传给 `CreateSolidBrush`/`SetTextColor`/`DrawText` 会得到错误颜色（表现为「黑块」「文字隐形」）。**一切交给 GDI 前必须 `app_cr()`**。命令面板一度只剩 4 行可见，就是这个原因（非自绘逻辑问题）。
2. **多行 EDIT 只认 `\r\n`**：把 `;` 换成 `\n` 看着没换行；必须 `\r\n`，否则设置里的高亮规则会挤成一行。
3. **`SS_SINGLELINE` 不存在**：STATIC 只有 `SS_LEFT/RIGHT/CENTER`，想要单行用 `SS_LEFT` 且不设 `SS_ENDELLIPSIS`（配 `SS_LEFT` 可用）。
4. **不要手绘多列文字**：快捷键窗口手绘时右列文字莫名变白，改用原生 STATIC 一次成功；能用控件就别自绘。
5. **命令面板不要在 `WM_DESTROY` 后读窗口结构体**：先存 `g_pal_exec`，销毁后再派发。
6. **截图脚本的尺寸过滤**：DPI 虚拟化下 `GetWindowRect` 返回逻辑尺寸，500px 对话框按 `>500` 会被漏掉。
7. **删标签要维护 `active_tab`**：`app_remove_root` 老 bug，删左侧标签会让活动标签跳到错误的那个。
