## 1. 产品目标

对标 **WindTerm / MobaXterm / SecureCRT** 的 Windows 运维终端：SSH/串口/本地/SFTP/转发/远程桌面，**整目录拷贝即可运行**，不依赖本机 OpenSSH、VC++ 红包。

## 2. 架构

```
UI (Win32)          Core                Engine (旁载库)
├─ 连接栏(密钥/跳板/转发) ├─ yt_paths      ├─ SSH+ProxyJump libssh2
├─ 会话树/属性      ├─ cred_store DPAPI ├─ Local ConPTY
├─ 多标签/分屏/布局 ├─ profile_store    ├─ Serial Win32
├─ TermView         ├─ layout_store     ├─ SFTP / Forward
├─ SFTP 侧栏        ├─ features(宏/串口)├─ ZMODEM/B64
├─ 快捷条/宏/脚本   └─ session          └─ RDP/VNC/X11/unix
└─ Bridge(Test)
```

- **便携根目录** = exe 所在目录；`config/` `logs/` `keys/` `themes/` `runtime/` 均相对此路径。
- **Release** 不含 UI Bridge；**Test** 开 `127.0.0.1:8086` 供 Agent 测。

## 3. 模块职责

| 模块 | 文件 | 职责 |
|------|------|------|
| 路径 | `src/core/paths.c` | 便携目录初始化 |
| 凭证 | `cred_store.c` | DPAPI 存密；主密码导入导出 |
| 会话档 | `profile_store.c` | sessions.json |
| 会话运行时 | `session.c` | 写/关/同步输入；时间戳日志 |
| 布局/特性 | `layout_store.c` `features.c` | 布局 JSON；宏/脚本/串口枚举/监控 |
| SSH | `engine/ssh_session.c` + `ssh_async.c` | 异步；密钥；ProxyJump 中继 |
| 本地/串口 | `local_pty.c` `serial_session.c` | ConPTY / CreateFile+DCB |
| SFTP/转发 | `sftp.c` `forward.c` | 懒加载 SFTP；L 端口转发 |
| 远程 | `remotes.c` | 启动 runtime 旁载 |
| 终端绘制 | `ui/term_view.c` | ANSI/UTF-8/拖选/搜索/导出 |
| 主窗 | `ui/main.c` `ui_extra.c` | 中文 UI + 全菜单 |
