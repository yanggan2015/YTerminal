# 主流终端工具优点提炼清单（对标用）

> 目的：把 WindTerm / SecureCRT / MobaXterm / PuTTY / Windows Terminal / Tabby / Xshell / iTerm2 的**公认优点**逐条拆出来，作为 YTerminal 的实现清单与验收口径。
> 状态图例：`✅` 已实现并可用 · `◐` 部分实现/有简化 · `○` 未实现（列入 Roadmap）
> 维护：每实现一项就把状态改掉，并在 `docs/评分表.md` 里重新打分。

---

|---|---|---|---|---|

## 8. 差距结论（按「对用户价值 / 实现成本」排序）

1. ~~**SFTP 双栏管理器**~~ **已完成**：双栏 + 队列 + 后台线程。
2. **Zmodem**（SecureCRT/Xshell 高频）——价值中高、成本高（需完整协议栈）。
3. **内置 SSH 栈**——去掉对 `ssh.exe` 的依赖，价值高、成本极高。
4. **自定义快捷键 + 命令历史补全**——价值中、成本中。
5. **触发器动作扩展 + 时间戳侧栏**——价值中、成本低。
6. ~~**窗口尺寸/分屏比例持久化**~~ **已完成**。

> 以上 1/4/5/6 属「低成本高感知」，应排在下一轮；2/3 属重工程，放 P1/P2。
