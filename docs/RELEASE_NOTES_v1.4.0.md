# YTerminal v1.4.0

纯 C、单 EXE 287 KB 的 Windows 全能终端。本版补齐**交互效率最后一块**与**配置可迁移**。

## 1. 命令历史 + Tab 补全

- 每个标签独立记录最近 **40 条**输入（空行不记、连续重复只记一次）
- `↑` / `↓` 整行召回：先按字符数发退格，再发历史文本；回到末尾恢复空行
- `Tab`：输入行非空且历史里**前缀唯一**时补全（如 `git che` → `git checkout main`）；有多个候选或没有匹配时，原样交给 shell 做路径补全
- `Enter` 入历史并清空当前行；`Ctrl+C` 清行
- **全屏程序不拦截**：`vim` / `less` / `top` 里 `↑` 仍然是程序的 `↑`（按 `vt_is_alt` 判断备用屏）
- 中文输入：按 UTF-8 码点计数发退格，不会一次删掉半个汉字

## 2. 快捷键配置导入 / 导出

- 「快捷键设置」新增「导入」「导出」两个按钮
- 导出为 `YTerminal-keys.txt`（`0=Ctrl+Shift+C;1=...`），可带到另一台机器
- 导入后先在列表里预览，点「保存」才写入 `settings.json` 生效；坏行自动跳过并提示
